# 🏀 Scoreboard Project

This is a dynamic scoreboard app built using HTML, CSS, and JavaScript, powered by Vite. Made during a Scrimba course to practice DOM manipulation and modular JS.

### ⚙️ Features
- Add and reset scores
- Home vs. Guest toggling
- Clean UI with responsive design

### 🛠 Built With
- HTML
- CSS
- JavaScript
- [Vite](https://vitejs.dev/)
